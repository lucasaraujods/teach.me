# Projeto de IA - Gerador de Perguntas e Feedback com ChatGPT

## Descrição

Este projeto utiliza a API do ChatGPT para gerar perguntas com base em um tema inserido pelo usuário e fornecer feedback sobre a resposta dada. Ele permite que o usuário insira um tema no input, a IA gera uma pergunta relacionada ao tema, e após a resposta do usuário, a IA realiza uma análise e oferece um feedback detalhado.

## Funcionalidades

- Inserir um tema para gerar perguntas automáticas.
- Responder perguntas sobre o tema.
- Feedback da IA sobre a resposta fornecida.
  
## Tecnologias Utilizadas

- **JavaScript**: Estruturação da lógica principal.
- **HTML**: Estrutura do layout da página.
- **CSS**: Estilos para o design e responsividade.
- **TypeScript**: Garantir tipagem no desenvolvimento React.
- **React**: Construção da interface dinâmica.
- **API do ChatGPT**: Para geração de perguntas e análise de respostas.
